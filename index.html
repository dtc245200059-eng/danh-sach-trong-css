5. Thay đổi vị trí dấu đánh dấu (list-style-position)

So sánh giữa outside (dấu nằm ngoài lề hộp nội dung) và inside (dấu nằm bên trong dòng văn bản):

Vị trí: outside (mặc định)

  • HTML: Ngôn ngữ đánh dấu siêu văn bản
  • CSS: Ngôn ngữ định kiểu giao diện web
  • JavaScript: Ngôn ngữ lập trình tạo tương tác

Vị trí: inside

  • HTML: Ngôn ngữ đánh dấu siêu văn bản
  • CSS: Ngôn ngữ định kiểu giao diện web
  • JavaScript: Ngôn ngữ lập trình tạo tương tác
